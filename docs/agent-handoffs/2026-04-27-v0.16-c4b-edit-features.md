## Goal

Land the user-facing edit surface that turns the C4a foundation into a real layer-aware editor: bind/tweak materials through a Material Sheet, hand-author USDA into the working layer through an Apply-only USDA panel, and swap shading models with one-shot atomic undo. Verify the Ctrl+S round-trip end-to-end with external `usdview` — the original C4 acceptance gate that C4a deferred (handoff 2026-04-22 line 123). Sync docs and ship v0.16.0.
