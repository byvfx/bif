## Goal

Clear the v0.16.0 Code Reviewer followup list and the older active BUGLIST entries that are real bugs (not deferred features) in one focused sweep. Ship as `v0.16.1`. The v0.16.0 release line stays untouched on `main`; this work lands on top.

User-visible outcomes after merge:

- Save errors name the actual cause (permission denied, write lock, etc.) instead of opaque "Save failed: error".
- Scene browser child counts match `usdview` for stages that previously had a visible gap.
- Property Inspector + workspace-switch + USDA Apply are crash-resistant against rapid selection / dock-rebuild / modal-reentry.
- HiDPI surfaces render gizmo / outline / hit-test pixels at the correct physical size.
- View → Grid toggles the viewport grid.
- Shading-model swap rolls back the `info:id` write if the input writes fail (no half-swapped material).

## Scope

### In scope (Tier 1 — small, low-risk, do first)

1. **TfErrorMark on save** — `usd_bridge_layer_save` returns the actual USD error message via a new out-param. Rust gets a `UsdBridgeError::SaveFailed(String)` variant. New negative test `save_with_locked_layer_returns_message`.
2. **Mutex-poison logging** — log on `Err(_)` of `stage_arc.lock()` in the 2 `main_window.rs` sites flagged by review.
3. **Scene-browser empty-path filter** — `CompositeProvider::get_children` filters empties at the source so Qt's index-based iteration can't drop them. New unit test.
4. **QPointer captures in `property_inspector_widget` lambdas** — replace raw `BifShellState*` captures with `QPointer<BifShellState>` + null guard at lambda top.
5. **Modal re-entrancy guard on `QMessageBox::question`** — defer the modal via `QTimer::singleShot(0, ...)` in the 2 sites flagged by review (`window_builder.cpp:267-276`, `property_inspector_widget.cpp:406-416`).
6. **Thread_local export-buffer contract test** — proves `_layer_export_as_string` returns a pointer that's invalidated by the next call on the same thread.

### In scope (Tier 2 — medium, focused)

7. **`cstr(s)` helper extraction** in `cpp_bridge.rs` — dedupe ~28 `CString::new(...).map_err(...)` sites. Pure refactor; gate must stay green.
8. **Grid on/off button** — new `DisplaySettings::grid_visible` (default true), `View → Grid` checkable QAction, qproperty + qinvokable, render path checks the bool. Mirrors the `View → Viewport LOD` pattern.
9. **Negative tests for v0.16.0 edit-op coverage** — add `save_without_permission_returns_error`, `undo_after_target_switch_targets_recorded_layer`, `replace_layer_double_apply_idempotent` to `tests/edit_op_roundtrip.rs`.
10. **Atomic shader-swap composite op (option B — Rust rollback)** — capture previous `info:id` before swap; if any subsequent input write fails, author the original `info:id` back before returning the error. Adds `shader_swap_input_failure_rolls_back_id` test.
11. **HiDPI scale factor — apply downstream** — wire `Renderer::scale_factor` into gizmo widths, outline params, and any other "px" uniform; verify with synthetic `scale_factor = 2.0` override on a non-HiDPI display before commit.

### Out of scope

- AOVs (feature work, separate v0.17+ planning).
- Viewport Vulkan ↔ Render mode switch (architectural change, ≥half-day).
- Full OCIO ACES integration (M21-class work).
- Pre-existing C++ bridge test crashes (`test_load_pointinstancer_external_prototype`, `test_load_relative_reference_usda`, `test_define_scope_prim`) — pre-existing, separate investigation.
- `inst.prim_path` empty-fallback root-cause work in `scene_loader` — partly mitigated by Tier 1.3; revisit only if the visible gap doesn't close.
- Server-side `usd_bridge_layer_swap_shader` composite FFI (option A from review) — option B is sufficient for v0.16.1.

## Constraints

- **No new clippy warnings.** `cargo clippy --all -- -D warnings` must stay clean.
- **Single-threaded test invariant.** `bif_core` tests still need `--test-threads=1` and `setup_usd_env.ps1` sourced. Do not parallelize.
- **C ABI safety.** Any new C-ABI entry point or signature change must keep `catch (...)` parity with the v0.16.0 hardening pass. Don't let an exception type other than `std::exception` unwind across the boundary.
- **Rust error variant addition (1.1) must keep existing call sites compiling.** Either add `SaveFailed(String)` as a non-breaking variant on the existing `UsdBridgeError` enum, or — if signature change forces breakage — fix every internal call site in the same commit.
- **Branch hygiene.** One commit per fix. Use the existing commit-message style (lowercase scope, terse subject, body explains *why*). Co-author trailer per project convention.
- **No emojis** in code, docs, or commit messages (project convention).
- **Don't push** until all of Tier 1 + Tier 2 are merged locally and the user is asked. Mirror the v0.16.0 release flow exactly.
- **Synthetic HiDPI verification (2.2):** Use a temporary `scale_factor = 2.0` constant override at the `bif_qt::Viewport::new` boundary (or a `BIF_FORCE_SCALE` env var read in the same place). Visually confirm gizmo line widths and outline widths visibly double on a non-HiDPI monitor. **Remove the override before commit.** Document the verification step in the 2.2 commit body.

## Acceptance Criteria

Each criterion below must be observably true before tagging `v0.16.1`.

### Tier 1

- **1.1.** Open a read-only USDA file. Trigger Ctrl+S. Status bar / log shows a message that names the real reason ("permission denied", "asset resolver could not write", etc.) — **not** a bare "Save failed: error". Test `save_with_locked_layer_returns_message` passes.
- **1.2.** Force a stage-mutex poison (e.g., panic in a USD callback in a one-off debug branch — do not commit). Confirm the next stage-touching slot logs an `error!` instead of silently no-op'ing. Revert the panic injection.
- **1.3.** On a stage that previously showed a visible Qt vs `usdview` child-count gap, confirm the Qt scene browser tree counts now match `usdview`. New unit test passes.
- **1.4.** Open Property Inspector. Rapidly toggle prim selection 20+ times while clicking action buttons. No crash, no warning about dangling pointer in logs.
- **1.5.** Trigger a `QMessageBox::question` from each of the 2 modified sites under selection-change pressure (rapid select-while-confirm). No double-fire of the surrounding slot.
- **1.6.** `cargo test -p bif_core --test ffi_contract -- --test-threads=1` passes; the test asserts byte-different content at the same pointer after the second `_layer_export_as_string` call.

### Tier 2

- **2.5.** All ~28 `CString::new(...).map_err(|_| UsdBridgeError::InvalidPath)` sites in `cpp_bridge.rs` replaced by `cstr(...)`. `cargo clippy --all -- -D warnings` clean. No behavior change in tests.
- **2.3.** `View → Grid` checkable action present in menu. Toggling hides / shows the grid in the viewport. Setting persists for the session (no need for QSettings persistence in v0.16.1 — defer if it adds scope).
- **2.4.** 3 new tests pass: `save_without_permission_returns_error`, `undo_after_target_switch_targets_recorded_layer`, `replace_layer_double_apply_idempotent`.
- **2.1.** Force a shader-input write failure (e.g., bad type in a debug branch) during a shading-model swap. Confirm the swapped-in `info:id` reverts to the original. New test `shader_swap_input_failure_rolls_back_id` passes.
- **2.2.** With synthetic `scale_factor = 2.0` override active on a non-HiDPI display: gizmo line widths and outline widths are visibly twice their unforced size. Override removed before commit. Manual verification step documented in 2.2 commit body.
