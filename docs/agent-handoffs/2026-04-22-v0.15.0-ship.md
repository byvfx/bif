## Constraints

- **Commit hygiene per `CLAUDE.md`:** Conventional commits, extremely concise messages, no commented-out code, no stray `println!`/`dbg!`. Each cleanup lands as its own commit (1a, 1b, 1c separately) — the docs bump and the CHANGELOG split should be their own commits too so the tag points at a tidy history.
- **No new behavior under the cleanup umbrella.** 1a preserves every visible attribute/stack/color value — it is a caching refactor. 1b changes perf/ergonomics, not composed results. 1c must produce identical trees to the eager path (same order, same nodes) — just populated on demand.
- **Backwards compatibility:** No invokable signatures change. Qt `SceneBrowserModel` continues to satisfy `QAbstractItemModel` contract; `fetchMore` must leave model in a consistent state for views that don't call it.
- **USD tests are single-threaded.** `cargo test -p bif_core -- --test-threads=1` after `setup_usd_env.ps1`.
- **Clippy clean across workspace** (`-D warnings`). Must fmt.
- **Ship date:** Use today's date for the `[0.15.0] - YYYY-MM-DD` header. If the work spans multiple days, use the day the tag is pushed.
- **No `--no-verify` commits, no history rewrites.**
