### Progressive Ivar Viewport (Feature)

- Added `accumulation_buffer`, `accumulated_samples`, `target_spp` to `IvarState`
- New `PassComplete` message variant and `reset_accumulation()`/`needs_more_passes()`/`is_pass_in_flight()` methods
- `pass_number` added to `RenderConfig`, XORed into per-pixel RNG seed
- Refactored `start_ivar_render()` into setup + `start_progressive_pass()` (1 SPP per pass)
- `poll_ivar_messages()` accumulates beauty into running sum, divides by pass count for display
- Main loop: auto-starts next pass when idle, camera/transform changes reset accumulation
- UI: SPP progress bar, per-pass bucket progress, target SPP slider (1-256)

## Learnings
- Collecting mpsc messages into Vec before processing avoids borrow conflicts when the handler needs to mutate the receiver field
- Progressive accumulation is simple: running sum / N, with pass_number XORed into RNG seed for different noise each pass
- AOVs (depth, normal) only need first pass — no benefit from accumulation
