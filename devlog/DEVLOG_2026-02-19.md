# Development Log - 2026-02-19

## Session Duration
~1.5 hours

## Goals
- Fix scatter dirty propagation (primitive size change → recompute)
- Hide scatter surface geometry from viewport
- Replace 1px point dots with sized/colored billboard circles

## What I Did

### Fix 1: Recursive Dirty Propagation
- Extracted `mark_node_dirty` from `SceneNodeViewer` to a `pub(crate)` free function
- Added `propagate_dirty()` — BFS walk of all downstream output connections
- Replaced 3 single-level dirty walks (CreatePrimitive, ScatterPointsCompute, DeleteNode)
- Chain `Primitive → ScatterPoints → PointInstancer` now recomputes correctly

### Fix 2: Hide Scatter Surface Geometry
- Added `scatter_surface_proto_ids: HashSet<usize>` and `node_scatter_surface_map: HashMap<NodeId, usize>` to Renderer
- Surface proto tracked on scatter compute, cleared on reconnect/delete
- `reload_working_scene()` merges scatter surfaces into `hidden_proto_ids` set
- Replaced all `instanced_proto_ids` filter references with `hidden_proto_ids`

### Fix 3a: Billboard Quad Point Rendering
- Switched pipeline topology from `PointList` to `TriangleStrip`
- Vertex shader uses `instance_index` for point lookup, `vertex_index` (0-3) for quad corners
- Screen-space quad offsets scaled by `point_size` pixels / viewport dimensions
- Fragment shader discards outside unit circle for round points
- Added `viewport_width`/`viewport_height` to `PointParams` uniform
- `update_params()` method for per-frame viewport sync without re-uploading points
- Draw call: `draw(0..4, 0..point_count)` — 4 verts per quad, one instance per point

### Fix 3b: Per-Node Color/Size UI
- Added `point_size: f32` and `point_color: [f32; 4]` fields to `ScatterPoints` variant
- New `PointPreviewUpdate` event (cosmetic only, no recompute)
- `DragValue` slider for size (1-20px), `color_edit_button_rgba_unmultiplied` for color
- Handler writes to `point_preview.point_size`/`color` and pushes params to GPU
- Scatter compute syncs node's color/size to preview renderer

## Learnings
- wgpu `PointList` renders 1px with no size control — `@builtin(point_size)` is not standard WebGPU
- Billboard quads via instanced TriangleStrip is the standard approach for sized points
- NDC offset = pixel_offset / viewport_size * 2.0, multiplied by clip_pos.w for perspective correctness
- BFS dirty propagation is cleaner than manually checking each node type at each level
