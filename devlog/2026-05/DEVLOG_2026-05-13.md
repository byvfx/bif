## Learnings

- **Read git log before re-implementing.** A 30-second `git log -S 'display_color'` would have surfaced 6262af5 and saved the chain trace. Net result was still a win (regression tests instead of duplicated code), but the user paid for the lookup.
- **cxx-qt 0.7 qproperty getter is `getFoo()` not `foo()`.** Compile-time catch by MSVC; worth a CLAUDE.md note.
- **Index-based access scales to 12 invokables fine.** No QStringList plumbing needed in cxx-qt 0.7. Count + indexed getters are mechanical; lists are small enough that round trips are invisible.
- **`UsdCollectionAPI::ComputeMembershipQuery` + `ComputeIncludedPaths`** is the canonical expansion path — handles all three rules + excludes + includeRoot in one call. Don't walk manually.
- **Token validation at the bridge layer.** `_set_expansion_rule` rejects unknown tokens before `attr.Set()`. Rust trusts C++ guard; C++ trusts no one. Saves USD coding-errors.
- **No-Line Rule is enforceable in QSS.** Delete every `border: 1px solid …`, use `border: none` + tonal shifts. `surface_container_lowest` 1px strips read as dividers without being lines.
- **Legacy alias constants migrate a palette without breaking dozens of call sites.** `pub const BG_BASE: Color = SURFACE;` — panels picking up Graphite colors silently while the door stays open for explicit renames.

### v0.16.6 — View ▸ Panels submenu + Reset Workspace Layout (`22a4a5f`)

Two features landed in one commit because they both touch `window_builder.cpp`.

Closing a dock via its `X` unchecks the menu entry, workspace switches that call `apply_default_layout()` propagate automatically.

- New `View ▸ Reset Workspace Layout` action: `QMessageBox::question` confirm → `QSettings().remove(state_key(current))` → `ws::apply_default_layout(window, current)`.
- All 8 panel toggles + reset action added to the command palette (Ctrl+P) entries.

## Key Decisions

- **Hotfix in its own branch, not bundled with v0.16.6.** Correctness fixes shouldn't queue behind UX work. Branch fast-forwarded onto `main` between feature commits.
- **`QTimer::singleShot(0, ...)` for initial dock-state seeding** instead of reordering the build-shell code. The wiring stays in the menu-action block (next to the related lambdas) and runs after dock construction finishes naturally.
- **Reuse `bif_qt::shortcuts::lookup()` registry** even though the v0.16 Preferences dialog doesn't exist yet. Future-proofs every new shortcut for remapping with zero extra work later.
- **Indexed-accessor `QAction` actions, not a global "panels" map.** Each dock has a named field on `MenuActions`. Keeps tab-completion + greppability strong.

## Learnings

- **Trust-but-verify reviewer output.** The `vfx-code-reviewer` was right on 4/5 high-severity findings but wrong on the expansion-rule validator (claimed missing, was present). 30 seconds of `grep` caught it before I "fixed" a non-bug.
- **cxx-qt 0.7 + bidirectional Qt signals is mostly fine without QObject subclassing.** As long as the cxx-qt-side signal exists (e.g. `BifShellState::collection_revisionChanged`), C++ widgets can connect both directions with lambdas. No friction.
- **QSS `::item { border-left: 4px solid X; }` beats a custom QStyledItemDelegate** for left accent stripes. Three lines of CSS replaced what would have been a 40-line delegate. The list-widget objectName-scoped selectors (`#includesList`) keep different roles distinct.
- **Inline-edit pattern: `QListWidget::setItemWidget` works but is fiddly.** Need to delete the transient item before the revision-bump refresh fires (otherwise the embedded `QLineEdit` dangles). Cancel-before-mutate ordering is critical.
- **The mockup HTMLs were the v0.16.6 contract.** Two minutes browsing `assets/stitch_bif_ui_01/assemble_*/code.html` was worth a half-hour of guessing what "Graphite-aesthetic inspector" meant.
