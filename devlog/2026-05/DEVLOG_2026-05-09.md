# Development Log - 2026-05-09

## Session Duration
~3 hours

## Goals
- Fix visibility toggle performance: eye icon hides were triggering full scene reload (GPU buffers, texture I/O, Embree BVH rebuild) causing multi-second stalls

## What I Did
- Deep-dive research: every production tool (Katana, Houdini, Bevy, Hydra, Pulsar) treats viewport visibility as a draw-skip flag, never a scene recomposition
- Traced full call chain: eye icon → `dispatch_visibility` → `apply_usd_edit` → `reload_after_usd_edit` → `reload_working_scene()` (full GPU rebuild + texture reload)
- Root cause: `reload_after_usd_edit()` set `materials_dirty = true` unconditionally, defeating the guard in `reload_working_scene()` that was designed to skip texture reloads on "display toggle"
- Implemented per-EditOperation dispatch in `reload_after_usd_edit()`:
  - Visibility → `reload_instance_visibility()` (instance groups + culling only, no GPU rebuild)
  - Transform → skip (local fast path in `handle_transform_edit` already writes GPU)
  - MaterialParamOverride → `reload_working_scene()` without `materials_dirty` (material table rebuild but no texture I/O)
  - Default → full `reload_working_scene()` with `materials_dirty = true`
- Created `reload_instance_visibility()` — filters instance arrays via visibility mask, rebuilds multi-draw instance groups and culling AABBs. Never mutates ground-truth arrays so hide→unhide is reversible.
- Added `full_material_ids`, `full_purposes`, `all_prim_paths` to `SceneInstances` for reversible filtering
- Post-hit visibility filter in `pick_instance_at` avoids Embree BVH rebuild
- Fixed cascading bug: `full_material_ids` guard self-destructed (re-cloned already-filtered data on every call)
- Fixed culling parallel array mismatch (filtered AABBs didn't match unfiltered current/material_ids/purposes)

## Learnings
- Visibility filtering must be reversible: keep ground-truth arrays untouched, build filtered views each time
- Multi-draw render loop self-uploads instances to GPU per frame — no need for explicit GPU buffer writes in the visibility reload
- cxx-qt panics unwind through C++ frames → need Qt env for full workspace clippy
- `debug_assert_eq!` in culling fires in debug builds on parallel array mismatch
