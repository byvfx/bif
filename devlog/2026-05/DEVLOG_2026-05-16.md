## Learnings

- The shortcut registry's `registered_defaults()` reflects whatever's been `lookup()`'d at runtime — so the dialog enumerates dynamically rather than from a static manifest. Trade-off: actions not yet routed through `sc::lookup` (File menu, Workspace menu) won't show up; conversion to lookup is a follow-up.
- `QAction::PreferencesRole` is the macOS habit — does no harm on Windows but makes future macOS port slot into the Apple menu correctly.
