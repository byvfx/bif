### Repro

`cargo run -p bif_viewer`, File → Open `test_assets/comprehensive.usda`:

```
thread 'main' panicked at crates\bif_math\src\interval.rs:14:
Interval::new called with min (NaN) > max (NaN)
```

### Root cause

Stack chain: `finalize_usd_scene` (scene_loader.rs:2267) → `Mat4Ext::transform_aabb` (transform.rs:47) → `Aabb::from_points` → `Interval::new(NaN, NaN)`.

`MeshData::bounds_min/max` are reduced over points from sentinel inits:

```rust
let mut bounds_min = Vec3::splat(f32::INFINITY);
let mut bounds_max = Vec3::splat(f32::NEG_INFINITY);
```

`comprehensive.usda` exercises variant swap + animated points + mute layers. At least one prototype reaches `transform_aabb` with zero points — sentinels survive, `bounds_min = +INF`, `bounds_max = -INF`.

Arvo's transform_aabb iterates matrix columns:

```rust
let a = col * aabb_min[i];   // col has zero off-diagonals → 0 * INF = NaN
new_min += a.min(b);
```

NaN propagates to `Aabb::from_points` → `Interval::new(NaN, NaN)` → `debug_assert!(min <= max)` fires (NaN comparisons are false).

### Fix

Root-cause first, defensive net second.

1. **`crates/bif_viewport/src/mesh_data.rs`** — collapse non-finite bounds to `Vec3::ZERO` at both reduction sites (single-mesh ~L448, combined-mesh ~L687).
2. **`crates/bif_math/src/aabb.rs`** — `Aabb::from_points` collapses non-finite input to zero AABB + `log::warn!`. Added `log` workspace dep to `bif_math/Cargo.toml`. Two new regression tests cover INF-sentinel + NaN.
3. **`BUGLIST.md`** — filed the proper fix (filter empty prototypes entirely in `finalize_usd_scene` ~L2230 with matching instance / prototype_ids cleanup) for v0.17.0 alongside the `cpp_bridge.rs` split.

## Learnings

- `glam::Vec3::is_finite()` returns true iff **all** components finite — covers INF + NaN in one check. Cleaner than `.x.is_finite() && .y.is_finite() && .z.is_finite()`.
- Sentinel-init reductions (`+INF / -INF`) silently corrupt downstream matrix math the moment they meet a transform with zeros. Always collapse the sentinel post-reduction, or never expose the sentinel state.
- `debug_assert!(min <= max)` with NaN is a half-finished invariant: NaN ≤ NaN is false, so the assert catches the corruption — but only after it has already poisoned the AABB. Push the check earlier (at the matrix-multiply source) when feasible.
