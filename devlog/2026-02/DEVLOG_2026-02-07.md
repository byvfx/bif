# Development Log - 2026-02-07

## Session Duration

~1.5 hours

## Goals

- Fix Ivar render aspect ratio squeeze
- Add infinite ground grid to viewport
- Add scene camera support (Camera primitives usable as render cameras)

## What I Did

### Item 1: Fix Ivar Render Squeeze (15min)

- **Root cause:** `ivar_build.rs` used `self.size` (full window) for camera resolution and render buffer, but Ivar result displays in `viewport_rect()` (smaller, excludes UI panels)
- **Fix:** `create_ivar_camera()` and `start_ivar_render()` now use `viewport_rect()` dimensions
- **Files:** `crates/bif_viewport/src/ivar_build.rs`

### Item 2: Infinite Ground Grid (45min)

- Fullscreen triangle + fragment shader ray-plane intersection (same technique as skybox)
- Anti-aliased 1m minor grid + 10m major grid via `fract()` + `fwidth()`
- X-axis red, Z-axis blue at origin
- Alpha fade with distance (200m max)
- `@builtin(frag_depth)` for correct occlusion by geometry
- Pipeline: alpha blend, depth read+write (LessEqual), reuses camera bind group
- Renders before geometry in the geometry pass
- **Files:** `crates/bif_viewport/src/shaders/grid.wgsl`, `crates/bif_viewport/src/grid.rs`, `render.rs`, `lib.rs`

### Item 3: Scene Camera Support (30min)

- `SceneCamera` struct in `bif_core/src/scene.rs` (name, instance_index, fov_y, near, far)
- `CameraSource::SceneCamera(usize)` variant in `ivar_state.rs`
- Camera primitives register as scene cameras during `load_primitive()`
- Scene cameras appear in timeline camera dropdown (after ortho presets)
- Selecting locks viewport, syncs pos/rot/FOV from instance transform
- Per-frame sync during animation playback (follows keyframed camera)
- Batch render falls through to viewport camera (already synced)
- **Files:** `scene.rs`, `ivar_state.rs`, `scene_loader.rs`, `render.rs`, `animation.rs`, `batch_render.rs`, `lib.rs`

### Item 4: Code Review Fixes (20min)

- Grid: `depth_write_enabled: false`, render after opaques (fix z-fighting with transparent grid)
- Ivar: extract `create_ivar_bind_group()` — stop recreating full GPU pipeline just for a bind group
- Grid shader: sync `CameraUniform` struct with Rust side (add `selected_instance_id` + padding)
- Scene camera: reset stale index on scene reload (prevent dangling `SceneCamera(idx)`)
- Camera prims: unique names in dropdown (`Camera`, `Camera_2`, etc.)
- **Files:** `grid.rs`, `grid.wgsl`, `ivar_renderer.rs`, `ivar_build.rs`, `lib.rs`, `render.rs`, `scene_loader.rs`

## Learnings

- wgpu `Depth24Plus` works fine with `@builtin(frag_depth)` output from fragment shader
- `fwidth()` in WGSL provides screen-space derivatives for anti-aliased procedural patterns
- Deferred event pattern via `egui::data_mut()` continues to scale well for new features
- Transparent surfaces must render AFTER opaques with `depth_write: false` — otherwise they pollute depth buffer
- GPU pipeline creation is expensive; extract bind group creation as separate function when only the bind group changes
