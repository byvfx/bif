## Learnings

- Ortho projection inverse naturally produces parallel rays - no special pick code needed
- `std::mem::forget(self)` in `save()` to prevent double-free when C++ side owns cleanup

## Session 3: M20 Code Review Fixes

### Session Duration

~1 hour

### Goals

- Fix all issues from VFX code review of M20 commit

### What I Did

#### P0 Fixes (Critical)

- **UsdEditLayer Drop/save split**: Separated C++ `save_edit_layer` (save only) and `free_edit_layer` (free only). Rust `Drop` now discards unsaved changes instead of silently saving to disk. Removed `std::mem::forget` hack.
- **Shared Embree FFI**: Created `embree_ffi.rs` with single source of truth for all Embree types/externs. Both `embree.rs` and `pick_scene.rs` now import from it. Eliminates duplication drift risk.
- **Vertex stride 16B**: Padded pick scene vertex buffer to 4 floats/vertex (16-byte stride) for Embree SIMD safety.

#### P1 Fixes (Important)

- **Stale pick scene**: Added `update_instance_transform()` to `EmbreePickScene` using `rtcGetGeometry` + `rtcSetGeometryTransform` + `rtcCommitScene`. Called from `apply_transform_override`, `set_live_transform`, `apply_all_transform_overrides`.
- **Undo cap**: Added `MAX_UNDO_COMMANDS = 1000` constant. Oldest commands dropped via `drain(..excess)` when exceeded.
- **Selection highlight**: Changed from additive `+0.15` (invisible on bright objects) to `mix(color, color * warm_tint, 0.35)` which scales with brightness.

#### P2 Fixes (Suggestions)

- **GizmoAxis**: Added `#[repr(u8)]` with explicit discriminants + `from_u8()` method. Eliminated implicit ordinal mapping in render.rs.
- **Ortho WASD**: Disabled W/S (forward/back) in ortho mode to prevent breaking preset axis alignment.
- **Sphere poles**: Replaced degenerate quad triangulation at poles with triangle fans. Updated test assertion (512 -> 480 triangles).

#### Deferred

- Renderer sub-struct extraction (56 call sites, P2) - better as focused refactoring session

### Issues Found

- bif_viewer.exe locked during build (running process) - harmless, linker error only

### Learnings

- Embree `rtcGetGeometry(scene, geom_id)` returns a handle to attached geometry for incremental updates - much cheaper than full BVH rebuild
- Separating C++ save/free eliminates fragile `mem::forget` ownership coupling
- Multiplicative selection highlight (`mix` with warm tint) is perceptually stable across all brightness levels
