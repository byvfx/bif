## Goals

- Fix 3 related bugs in primitive/instancing pipeline

## What I Did

### Bug 3: Grid/Sphere scale params ignored

- `generate_grid_points()` and `generate_sphere_points()` now accept `&ScatterConfig`
- Generate per-point scales, orientations, IDs (same pattern as `scatter_on_surface`)
- Sphere uses `config.seed.wrapping_add(1)` for attribute RNG to keep positions deterministic
- Updated render.rs call sites to build ScatterConfig from ScatterPointsParams
- Added `grid_points_have_scales` and `sphere_points_have_scales` tests

### Bug 1: Primitives require manual "Create" click

- Replaced button with auto-create (same pattern as ScatterPoints auto-compute)
- Size drag sets `is_created = false` → re-fires CreatePrimitive next frame

### Bug 2: Original prototype visible after instancing

- Root cause: CreatePrimitive didn't clean up old proto on re-creation → orphans
- Fix: remove old prototype via `remove_and_reindex_prototype()` before creating new
- Dirty downstream instancers (reset is_instanced, is_computing, compute_failed)
- Added debug log for instanced_proto_ids filtering

### DRY refactor

- Extracted `remove_and_reindex_prototype()` helper on Renderer (scene_loader.rs)
- Refactored DeleteNode handler to use same helper

## Files Changed

- `crates/bif_core/src/scatter.rs` — grid/sphere config param, per-point attrs, 3 new tests
- `crates/bif_viewport/src/node_graph.rs` — auto-create pattern
- `crates/bif_viewport/src/render.rs` — proto cleanup, downstream dirty, grid/sphere call sites, DRY DeleteNode
- `crates/bif_viewport/src/scene_loader.rs` — remove_and_reindex_prototype helper, debug log

## Learnings

- Orphaned prototypes from re-creation cause visible artifacts — always clean up before re-creating
- Separate RNG seeds (wrapping_add) keep position generation deterministic while adding attribute randomness
