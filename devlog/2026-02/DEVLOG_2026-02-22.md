- **materials_dirty flag** — skip expensive texture rebuild on Xform drag / display toggle.
- **Identity Xform early-out** — skip no-op transforms.
- **Removed filesystem exists()** — from `resolve_texture_path` hot path.
- **Replaced egui temp data** — `xform_property_changed` field instead of fragile temp data bus.

### Learnings

## Session 3: VFX Code Review — Full 9-Fix Plan (~2.5 hours)

### Goals

- Complete remaining VFX code review fixes (6-9)
- Implement all 9 fixes from the review plan

### What I Did

**Fix 1 — Parser .unwrap() safety:**

- Changed peek+unwrap pattern to use peeked value directly in 3 functions
- Added 3 malformed-input unit tests (no panics)

**Fix 2 — Remove test eprintln:**

- Replaced `eprintln!` in test code with meaningful assertions
- Kept informational skip messages

**Fix 3 — Culling buffer dirty flag:**

- Added `buffer_dirty: bool` + `cached_result: CullingResult` to `CullingManager`
- Early return when `!buffer_dirty && !camera_changed` (skips 8MB GPU write)
- `mark_dirty()` called from transform overrides, scene load, scatter ops

**Fix 4 — Arc\<str\> refactor:**

- `Material.name`, all texture paths, `Prototype.name`, `Instance.prim_path` → `Arc<str>`
- `impl Into<Arc<str>>` on public APIs for ergonomic callers
- 18 downstream type errors in bif_viewport fixed

**Fix 5 — Async USD loading:**

- `mpsc::channel` + `std::thread::spawn` pattern (matches existing `ivar_build.rs`)
- `UsdLoadStatus`/`UsdLoadProgress`/`UsdLoadMessage` enums
- Spinner + status text in top panel during load
- GPU finalization on main thread via `finalize_usd_load()`

**Fix 6 — Stage metersPerUnit/upAxis + UI:**

- C++ `usd_bridge_get_stage_metadata()` reads `UsdGeomGetStageMetersPerUnit` + `UsdGeomGetStageUpAxis`
- Rust FFI: `UsdBridgeStageMetadataRaw` → `UsdStageMetadata` with `UpAxis` enum
- Display in top panel: `[Z-up, cm]` format
- Checkbox toggles: "Z→Y" axis correction, "→m" unit scaling (default OFF)
- Applies correction matrix to all instances in `reload_working_scene`
- Clippy caught `large_enum_variant` — boxed `Scene` in `UsdLoadMessage::Complete`

**Fix 7 — Embree BVH transform update:**

- `update_transforms(&mut self, transforms: &[Mat4])` method
- Uses `rtcGetGeometry` + `rtcSetGeometryTransform` + `rtcCommitScene`
- Avoids full geometry rebuild for transform-only changes

**Fix 8 — Magic numbers → named constants:**

- `DEFAULT_NEAR_PLANE` (0.1), `DEFAULT_FAR_PLANE` (100.0) in camera.rs
- `LOD_BOX_TRIANGLES` (12) in render.rs stats display

**Fix 9 — HashMap → IndexMap:**

- `prototype_map` + `material_map` in loader.rs → `IndexMap` for deterministic ordering
- Added `indexmap = "2"` to bif_core/Cargo.toml

### Issues Found

- **Missing C++ include** — `<pxr/usd/usdGeom/metrics.h>` needed for `UsdGeomGetStageMetersPerUnit`
- **Borrow checker** — can't call `self.reload_working_scene()` inside egui closure (borrows `self`). Used egui temp data flag + deferred handler pattern.
- **Clippy large_enum_variant** — `UsdLoadMessage::Complete` holds `Scene` (~280 bytes). Boxed it.
- **FFI dead_code warning** — `UsdBridgeUpAxisRaw::Z` flagged as unused (populated by C FFI). Added `#[allow(dead_code)]`.

### Learnings

- `Arc<str>` refactors cascade: changing a struct field type ripples through all constructors, closures, and HashMap key types
- IndexMap is a drop-in replacement for HashMap (same `.get()`, `.insert()`, `.iter()`)
- egui's borrow model means UI changes that trigger expensive recomputation must be deferred via flags
- Embree's `rtcGetGeometry` lets you update attached instances without storing handles
