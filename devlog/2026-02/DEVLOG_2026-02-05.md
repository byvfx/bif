## Session 3 Duration
~15 min

## Goals
- Fix RT playback stall: timeline not advancing in realtime mode

## What I Did
- Root cause: slider `.integer()` rounds sub-frame values every frame, triggering `changed()` which resets the playback anchor → timeline stuck oscillating
- Fix: gate slider writeback with `is_pointer_button_down_on()` so only user drags reset the anchor, not programmatic rounding
- Single edit in `crates/bif_viewport/src/lib.rs` (~line 4103)

## Learnings
- egui `Slider::integer()` quantizes every frame, fires `changed()` even for programmatic updates
- `Response::is_pointer_button_down_on()` distinguishes user interaction from programmatic changes
