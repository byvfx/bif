### Export Sublayer Fix (this session)
- **Root cause:** `collect_export_context()` didn't collect source USD path from upstream UsdRead nodes. Export used `self.loaded_usd_path` which was fragile/None.
- `collect_export_context()` now returns 3-tuple: `(authored_prims, graft_prefix, source_usd_path)`
- Walks upstream BFS, captures `file_path` from `UsdRead { is_loaded: true }` nodes
- Canonicalizes to absolute path via `std::fs::canonicalize()`
- Auto-enables `as_sublayer` when upstream UsdRead found
- Falls back to `self.loaded_usd_path` for backwards compat
- UsdPrim default path changed from "/World" to "/root" (avoids overwriting imported scene root)
- `loaded_usd_path` in scene_loader now stored as canonical absolute path
- Added diagnostic logging: debug/info/warn around sublayer logic

## Learnings
- USD sublayer resolution is relative to the output layer's directory, not CWD — absolute paths are essential
- `DefinePrim("/World", "Scope")` in edit layer overrides sublayer's `/World` (stronger opinion wins)
- Walking the node graph upstream to collect context is the right pattern for export — avoids fragile global state
