## Session 3

## Session Duration

~3 hours

## Goals

- Fix ALab material/texture binding after instance proxy support

## What I Did

### 7 bugs fixed in material/texture pipeline

1. **Material dedup** (C++) — `cache_material_data()` visited same material per instance proxy. Added `seen_material_paths` set keyed on prototype path. 376→132 unique materials.

2. **Proxy mesh material binding** (C++) — `mesh_material_paths` used `GetPrimAtPath()` which fails for virtual proxy paths. Added `bound_material_path` on `CachedMesh`, resolved during traversal with live prim.

3. **Empty face_material_ids** (C++) — Code always populated `face_material_ids` with zeros even without GeomSubsets. Shader used material 0 for ALL faces. Fix: only populate when GeomSubsets exist.

4. **Undersized tri-mat buffer** (Rust) — When all face_material_ids are sentinel, buffer was shrunk to 1 element. GPU OOB storage reads return 0 (not 0xFFFFFFFF), so shader still used material 0. Fix: always use full-sized buffer.

5. **UDIM texture path resolution** (C++) — Relative UDIM paths (`../../texture/.../<UDIM>.jpg`) resolved against stage root instead of source layer. Added `resolve_asset_path()` using `SdfComputeAssetPathRelativeToLayer()` with shader's source layer from `GetPrimStack()`. 30→127 textures loaded.

6. **Path slash normalization** (Rust) — C++ `SdfComputeAssetPathRelativeToLayer` returns backslash paths on Windows, but texture `index_map` keys use forward slashes. Added `replace('\\', "/")` normalization in `MaterialGpu::from_material()`.

7. **Purpose filtering** (C++) — `GetPurposeAttr().Get()` only reads directly-authored purpose. ALab sets purpose on parent Xforms. Switched to `ComputePurpose()` for inherited purpose. Eliminated Z-fighting from proxy/render mesh overlap.

### Debugging approach

- Added temporary C++ `std::cout` debug prints for material paths, GeomSubset children, mesh bindings
- Added Rust `log::warn!` for texture path mismatch diagnosis
- Iterative: fix, build, launch viewer, load ALab, check output, repeat (~8 cycles)

## Issues Found

- Instance proxy children not visible via `GetAllGeomSubsets()` — ALab uses mesh-level material binding, not per-face GeomSubsets
- `SdfComputeAssetPathRelativeToLayer()` returns Windows backslashes vs Rust forward slashes
- 272 texture paths but MAX_VIEWPORT_TEXTURES=128 — half the textures dropped

## Remaining

- Texture mapping still wrong on some meshes (may be UDIM atlas ordering or UV offset)
- Ivar material assignment broken (combined mesh needs per-instance→per-triangle mapping)
- Texture limit: need to increase MAX_VIEWPORT_TEXTURES or prioritize diffuse

## Learnings

- USD `GetPrimAtPath()` fails for instance proxy virtual paths — must resolve during traversal
- USD `face_material_ids` of 0 ≠ "no material" — 0 means "material index 0". Use None/sentinel for "no assignment"
- GPU storage buffer OOB reads return 0, not undefined — critical for sentinel-based material lookup
- `SdfComputeAssetPathRelativeToLayer()` anchors relative paths against the layer that authored them
- `ComputePurpose()` computes inherited purpose; `GetPurposeAttr().Get()` only reads directly-authored
