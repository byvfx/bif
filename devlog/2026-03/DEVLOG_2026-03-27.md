## Key Decisions
- New crate rather than inside bif_core — keeps CLI/subprocess deps separate
- Trait-based metrics (object-safe `dyn Metric`) — each metric is one file, composable
- No thread safety needed — benchmarking is inherently sequential for accuracy
- Scene registry is declarative data, not config file — simple, type-safe
- Stats module uses pure Rust math — no external stats crate

## Learnings
- USD's official methodology: 100 iterations, warm FS cache, min/max/mean
- `usdmeasureperformance.py` supports custom metrics via `testUsdviewInputFunction()`
- maxperf.html key tips: jemalloc (2x), binary .usdc, payloads, minimize prims, monitor layers
- clippy now enforces `is_none_or()` over `map_or(true, ...)` and `is_multiple_of()` over `% == 0`
