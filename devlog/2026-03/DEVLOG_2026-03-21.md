## Goals

- Fix purpose filtering bugs (double-filtering + missing paths)
- Fix grey/missing materials on some USD assets

## What I Did

- Removed double purpose-filtering in ivar_build.rs (async + sync paths) — combined mesh already filtered by reload_working_scene, second filter caused material index misalignment
- Removed verbose debug logs from purpose filtering implementation
- Added material diagnostic logging to trace texture loading and material params through Ivar pipeline
- Discovered UsdPreviewSurface specularColor→specular_weight mapping bug: averaging RGB to weight meant specularColor=(0,0,0) disabled specular entirely, breaking all dielectric materials
- Fixed: UsdPreviewSurface specular_weight always 1.0 (specular controlled by IOR/Fresnel, not weight)
- Tested with Nvidia Distributable assets (Glasses, BottleA, Hourglass, BookOpen)
- Glasses.usd: all UDIM textures load correctly including normal maps
- BottleA.usd: parametric materials (no textures), now renders with proper Fresnel
- Hourglass.usd: grey in BIF and Houdini — confirmed asset issue
- Moved all diagnostic logging to log::debug! for RUST_LOG-gated debugging
- Also downgraded embree ray hit logs and mesh_data per-face material logs

## Learnings

- UsdPreviewSurface `specularColor` is a tint on specular reflection, NOT a weight — averaging to specular_weight is semantically wrong. OpenPBR separates these as specular_weight (enables specular) and specular_color (tints it)
- When debugging material pipeline: trace from C++ bridge → FFI struct → Rust Material → OpenPBR surface to find where values get lost or misinterpreted
- Pre-warmed Ivar materials skip build_materials(), so diagnostic logging must be in from_material_with_textures() to fire on every build
- log::debug! + RUST_LOG is the idiomatic Rust approach for debug flags — no custom infrastructure needed

## Session 2 (~3 hours)

### Goals

- Make USD loading as fast as possible
- Fix crashes on large scenes

### What I Did

- Added Stage::Load() for eager USD composition — 8.3x speedup (8.8s→1s on Glasses.usd)
- Diagnosed "Normals: 8272ms" as USD lazy eval, not algorithmic issue (confirmed read=1ms after fix)
- Deferred normals copy past UV seam split — saves 289ms (24MB wasted copy on faceVarying meshes)
- Bulk vertex/normal copy via assign() replacing push_back loops
- UV seam split std::map→unordered_map (O(1) lookups)
- Rust loader: deferred .clone() past dedup check (skip clones for duplicate meshes)
- Added GPU buffer size guards (vertex, index, triangle material) — prevents crash on 342M vert scenes
- Chunked texture loading (16 at a time), paced GPU uploads (32/frame)
- UDIM atlas cap 64MP→16MP, texture count warning >511
- Disabled Ivar prewarm (on-demand materials, saves 8+ GB RAM)
- Architecture review: Software Architect + Code Reviewer graded codebase (A crate arch, B+ god object, C+ load perf → now fixed)

### Learnings

- USD lazy eval is the dominant load cost — Stage::Load() is the single highest-ROI optimization
- faceVarying normals get rebuilt during UV seam split — copying them beforehand is 100% wasted work
- 342M vert scenes need GPU buffer guards at every create_buffer_init call (vertex, index, material)
- Ivar prewarm loads ALL textures in f32 = massive RAM on large scenes
