## Goals

## What I Did

- **Root cause:** C++ bridge skipped `transmission` and `specular_IOR` from MaterialX standard_surface. Glass (transmission=1, roughness=0) rendered as smooth white dielectric.
- **C++ bridge** (`usd_bridge.h`, `usd_bridge.cpp`): Added `transmission` + `specular_ior` to `CachedMaterial` and `UsdBridgeMaterialData`. Extract from MaterialX (`transmission`, `specular_IOR`), ND_standard_surface, and UsdPreviewSurface (`ior` + opacity→transmission heuristic).
- **Rust FFI** (`cpp_bridge.rs`): Added fields to `UsdBridgeMaterialDataRaw` + `UsdMaterialData`, wired `get_material()`. Replaced hardcoded `specular_ior: 1.5` with actual C++ value.
- **Scene** (`scene.rs`): Added `transmission_weight` to `Material` struct.
- **Loader** (`loader.rs`): Map `transmission_weight` in material construction.
- **OpenPBR** (`openpbr.rs`): Added `transmission_weight` field, `scatter_transmission()` method (Snell's law + TIR + Schlick Fresnel reusing existing `refract()`), `glass(ior)` constructor, updated `is_delta()`. 3 new tests.

## Key Decisions

- Transmission check in `scatter()` happens after opacity but before diffuse/specular lobe selection — stochastic blend via `gen_f32(rng) < transmission_weight`
- UsdPreviewSurface heuristic: `opacity < 1` + `metallic == 0` → `transmission = 1 - opacity` (matches Houdini convention)
- Glass attenuation is `Color::ONE` (no absorption tint) — transmission_color is future work

## Learnings

- repr(C) struct field order matters — new fields must be inserted at same position in both C++ and Rust
- `HitRecord` has `material: &dyn Material`, not `material_id` — lifetime-bound reference
