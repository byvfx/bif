### Session 2: Architecture & Roadmap Evaluation

Evaluated 7 feature areas against ~42K LOC architecture. Key decisions:

- **Keep nodes** — operations (verbs), not scene hierarchy. Correct for scene assembly.
- **No MDL** — MaterialX is ASWF standard. MDL is Nvidia-only dead end.
- **Python hooks via PyO3** — embedded interpreter (like Houdini/Maya/Nuke), not subprocess
- **Framework: "Arch Linux for VFX"** — library crates → widget crates → plugins → DCC connectors
- **File formats** — `.bif` (bincode) + `.bifa` (JSON pretty-print), like Maya's `.mb`/`.ma`
- **Vertical node layout** — egui-snarl 0.6+ `NodeLayout::Sandwich`, needs egui 0.30
