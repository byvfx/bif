## Learnings

- Cranley-Patterson rotation needs different irrationals per dimension to avoid diagonal correlation
- Multi-SPP blue noise requires per-sample (not per-pass) index offset — easy to miss
- Box filter evaluate() returns 1.0, so single-loop approach works without branching
- Void-and-cluster at 256x256 takes ~2 min to generate (O(n²) pixel iterations)
- VFX code reviewer caught the multi-SPP bug — very useful for production correctness
