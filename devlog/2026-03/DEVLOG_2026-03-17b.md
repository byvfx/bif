# Development Log - 2026-03-17 (Session B)

## Goals

- Migrate material system from Disney Principled BSDF to OpenPBR Surface v1.1

## What I Did

### Disney → OpenPBR Migration (all phases complete)

**Phase 1: Core type rename**

- Deleted `disney.rs`, created `openpbr.rs` with `OpenPbrSurface` struct
- 22 OpenPBR fields (base, specular, coat, fuzz, subsurface, emission, geometry)
- IOR-based Fresnel: `F0 = ((ior-1)/(ior+1))^2 * specular_weight`
- Metal F0 = `base_color * base_weight` (not luminance-tinted)
- Kept GGX + Smith geometry, Burley diffuse, same sheen→fuzz approximation

**Phase 2: bif_core::Material**

- All fields renamed to OpenPBR: diffuse_color→base_color, metallic→base_metalness, etc.
- Added specular_ior (1.5), emission_luminance (0.0)
- Defaults: roughness 0.5→0.3, specular 0.5→1.0, base_color grey 0.5→0.8

**Phase 3: GPU structs**

- MaterialUniform: `base_color[r,g,b,metalness]` + `specular_params[roughness,ior,weight,pad]`
- MaterialGpu: added `emission[r,g,b,luminance]` + `extra_params[opacity,...]` (64→96 bytes)

**Phase 4: WGSL shader**

- IOR-based F0 calculation, metallic→metalness, specular_weight from params

**Phase 5: Pipeline**

- Updated embree.rs, batch_render.rs, ivar_build.rs, ivar_state.rs, bif_viewport/lib.rs
- Updated scene_loader.rs, texture_loader.rs, loader.rs, cpp_bridge.rs (UsdMaterialData)
- C++ FFI struct unchanged (raw field names cosmetic, types/order match)

**Phase 6: Export**

- cpp_bridge.rs write_material() uses new Material field names
- Export pipeline unchanged (C++ creates ND_open_pbr_surface already)
