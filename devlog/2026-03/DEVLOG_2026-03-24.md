## Learnings

- egui-snarl 0.5 has a `serde` feature that makes `Snarl<T>` fully serializable — nodes, connections, and positions all included
- `#[serde(skip, default)]` works on individual fields within enum variants — clean way to separate persistent vs runtime state
- Camera contains glam::Vec3 which needs `glam/serde` feature — cleaner to use a CameraData intermediary with `[f32; 3]` arrays
