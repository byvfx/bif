## Learnings

- usdMtlx plugin composes .mtlx files with an **interface pattern**: all shader inputs connected to Material prim inputs (not authored on shader). Must follow connections to read scalar values.
- Connection path format: `/Material.inputs:base_metalness` — `GetName()` returns full property name including `inputs:` namespace prefix
- MaterialX-in-USD is the standard pattern for OpenPBR spec — increasingly common in DCC exports
- vcpkg manifest mode vs classic mode: `vcpkg install` from project dir with vcpkg.json triggers manifest mode. Must use `--recurse` or run from vcpkg root for classic installs.
