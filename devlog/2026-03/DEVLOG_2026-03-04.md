## Learnings

- `bytemuck::cast_slice` for zero-copy `&[f32]` → `&[u8]` — avoids manual byte conversion loops
- Schlick F0 for dielectrics: `((1-ior)/(1+ior))²` gives physically plausible albedo for glass
- First-hit-only albedo: recursive bounces pollute albedo AOV with indirect surface colors
- `DenoiseState` pattern: grouping related fields into sub-struct reduces God object sprawl
- Async denoise with mpsc channel: spawn thread, send result, poll in UI loop — keeps viewport responsive
- Compact tri-mat buffer: one copy of per-tri material IDs per prototype, offset via instance data — avoids O(instances × triangles) buffer bloat
- `materials_dirty` flag triggers full texture reload — only set when actually importing new textures (UsdRead), not for built-in primitives
