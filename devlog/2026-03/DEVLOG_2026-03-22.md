## Learnings
- Unbounded mpsc channels are hidden memory bombs — always use sync_channel for data-heavy messages
- Deferred optimizations must handle ALL code paths — the no-UV fallback was missed
- MSVC std::hash<int> is literally identity → custom hash mixing essential for sequential keys
- Production scenes (335M verts) need fundamentally different approach than small assets
