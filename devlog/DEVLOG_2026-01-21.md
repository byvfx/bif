## Learnings

### OIIO 3.0 API Changes
The `ImageBufAlgo::make_texture()` function signature changed in OIIO 3.0:
```cpp
// OIIO 3.0 signature
bool make_texture(MakeTextureMode, const ImageBuf&, string_view, const ImageSpec&, std::ostream*)
```
The error stream is now `std::ostream*`, not `std::string*`.

### vcpkg Library Versioning
vcpkg OpenEXR/Imath have version numbers in lib names:
- `OpenEXR-3_4.lib` (not `OpenEXR-3_3.lib`)
- `Imath-3_2.lib` (not `Imath-3_1.lib`)
- `libpng16.lib` (not `png16.lib`)

Must check actual installed versions when linking.

### Feature Flag Patterns
For conditional compilation across crate boundaries:
```toml
# In dependent crate
[features]
oiio = ["bif_core/oiio"]
```
