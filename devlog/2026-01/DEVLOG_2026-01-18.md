# Development Log - 2026-01-18

## Session Focus

GeomSubset per-face materials + texture loading optimization

## What I Did

### 1. GeomSubset Support for Per-Face Materials

**Problem:** Palm coconut USD showed all faces with same material (bark texture everywhere)

**Root Cause Discovery:**

- C++ bridge extracted GeomSubsets correctly (15 subsets found)
- BUT materials cached AFTER meshes, so subset→material lookup failed
- Also: Houdini exports `__subdivs__` subset (all 345262 faces) with no material binding

**Fix:**

- Added forward declaration for `cache_material_data()`
- Call it BEFORE mesh caching in `cache_stage_data()`
- Skip subsets without valid material bindings (e.g., `__subdivs__`)

**Key Files:**

- `cpp/usd_bridge/usd_bridge.cpp` - Material caching order, skip non-material subsets
- `crates/bif_core/src/mesh.rs` - Added `face_material_ids: Option<Vec<u32>>`
- `crates/bif_viewport/src/lib.rs` - Unindex meshes for per-face materials

### 2. Texture Loading Optimization (25s → 1s)

**Problem:** 13 textures took ~25 seconds to load (vs fast in Houdini)

**Root Cause:** Sequential loading + PNG decode + per-pixel powf() for sRGB

**Fix:**

- Added sRGB to linear lookup table (avoid powf per pixel)
- Moved texture loading + downscaling to parallel phase with rayon
- Only GPU upload remains sequential

**Result:** 25s → ~1s (25x faster)

**Key Files:**

- `crates/bif_core/src/texture.rs` - Timing diagnostics, sRGB LUT
- `crates/bif_viewport/src/lib.rs` - Parallel texture processing

### 3. Vertex Deduplication with primitive_index (404MB → 78MB)

**Problem:** Lucy model (2.8M triangles) exceeded wgpu's 256MB buffer limit

**Root Cause:** Per-face materials required "unindexing" mesh - creating 3 unique vertices per triangle to store material_id per-vertex. 8.4M vertices × 48 bytes = 404MB

**Fix:**

- Keep mesh indexed with shared vertices (~1.4M vertices)
- Store per-triangle material IDs in separate storage buffer (~11MB)
- Shader uses `@builtin(primitive_index)` to look up material per-triangle
- Enabled `SHADER_PRIMITIVE_INDEX` wgpu feature
- Also increased `max_buffer_size` to 1GB as quick fix

**Result:** 5x memory reduction (404MB → ~78MB)

**Key Files:**

- `crates/bif_viewport/src/lib.rs` - MeshData.triangle_material_ids, buffer creation
- `crates/bif_viewport/src/shaders/basic.wgsl` - primitive_index material lookup

## Learnings

### USD GeomSubsets

- GeomSubsets define face indices per material
- Material binding can be on subset prim or inherited from parent
- Houdini exports metadata subsets (`__subdivs__`) - must check for material binding

### Texture Performance

- PNG decode dominates texture load time (50-90%)
- LUT avoids expensive powf() per pixel (256 entries vs millions of pixels)
- Parallel IO + decode massively helps (rayon)
- GPU upload still ~11s due to downscaling in upload phase

### GPU Per-Primitive Data

- `@builtin(primitive_index)` in WGSL gives triangle index in fragment shader
- Requires `SHADER_PRIMITIVE_INDEX` wgpu feature
- Enables per-triangle data without duplicating vertices
- Much better than unindexing mesh (5x memory savings for Lucy)
