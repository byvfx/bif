## Learnings
- **The system existed; the playbook didn't.** Release notes were changelog-driven all along — but the steps had to be reconstructed. Now in CLAUDE.md.
- **Dated changelog headers** (`## [x] - DATE`) broke the version-notes regex (`\s*\n` can't span ` - DATE`) — silently fell back to `[Unreleased]`. Fixed to `[^\n]*\n`.
- **PR is the review unit, not the commit** — and the repo was already wired for it (`claude-code-review.yml`). This session's earlier direct-to-main + force-push was the firefighting exception.
- **bif_viewport tests need `setup_usd_env.ps1`** (transitive USD link → `STATUS_DLL_NOT_FOUND`). Promoted to CLAUDE.md Gotchas.
- **Subagent delegation for mechanical refactors** works well: hand the translation table + compiler error list, verify the green gate. Kept the migration out of my context while staying in control.
- **Catch suspicious version numbers** — `v1.21.1` typo caught before a public tag (project is v0.16.x).
