## What I Did

### Multi-mesh Rendering Fix
The viewport only rendered the first prototype, causing scenes with multiple meshes (like `animated_cube.usda` with ground plane + cube) to only show the ground plane.

**Fix:** Added `MeshData::combine_with_transforms()` that:
- Merges all prototype meshes into single vertex/index buffer
- Bakes instance transforms into vertex positions
- Uses single identity-transform instance for rendering

### Vertex Animation Implementation
Added C++ API and Rust FFI for vertex animation (point deformation):
- `usd_bridge_get_mesh_vertex_animation_info()` - check if mesh has animated vertices
- `usd_bridge_get_mesh_vertices_at_time()` - query interpolated vertices at frame
- `update_vertex_animation()` in viewport - updates GPU buffer

**Issue found:** When meshes are combined, vertex offsets don't match USD mesh indices:
```
[WARN] Vertex count mismatch: USD has 8 vertices, mesh_data has 108
```
The combined mesh has 108 vertices (100 ground + 8 cube), but USD queries return 8.
