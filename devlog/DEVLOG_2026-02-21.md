## Goals
- Build headless A/B benchmark for SHARC radiance cache to measure speedup objectively

## What I Did
- Created `crates/bif_renderer/examples/cache_bench.rs`
  - Programmatic Cornell box (5 walls + light + 2 spheres, 12 tris)
  - 32 progressive 1-SPP passes, cache OFF then ON
  - Parallel bucket rendering via rayon (same as production)
  - Prints per-pass timing, cumulative hit rate, occupancy
- Ran benchmark in release mode

## Results
- Cache OFF: ~6ms/pass (201ms total)
- Cache ON: ~10ms/pass (327ms total) — **0.62x (slower!)**
- Hit rate: 5.1% after 32 passes, occupancy: 59%
- Cache overhead (hash + RwLock per bounce) dominates for trivial BVH

## Learnings
- SHARC cache has non-trivial per-ray overhead from sharded RwLock
- Simple scenes (12 tris) are too cheap for cache to break even
- Need complex geometry where BVH traversal cost >> cache lookup cost
- Hit rate limited by `min_samples: 4` — cells need many passes to become trusted
