- **Removed auto-instancing**: Scatter no longer calls `expand()`, `add_instance()`, or `reload_working_scene()`. Output is points only, displayed via point preview.

- **Grid generator** (`generate_grid_points`): spacing-based, centered at origin, Y=0 collapses to flat plane, safety cap via max_count
- **Sphere generator** (`generate_sphere_points`): Fibonacci sphere for surface, rejection sampling for volume
- **Lloyd relaxation** (`relax_points`): spatial hash grid, linear falloff repulsion, surface projection via `closest_point_on_triangle`
- **New node UI**: source dropdown at top, conditional params per source, relax section, max_point_limit safety cap
- **Simplified `remove_point_cloud`**: no longer truncates instances
- **Updated undo handler**: AddPointCloud no longer expands instances
- **Added `Grid`/`Sphere` to `DistributionMethod`** enum
- **Auto-enable point preview** on scatter compute
- **8 new tests**: grid count, 3D grid, flat grid, sphere surface, sphere volume, relax min distance, relax deterministic, max point limit cap
