## Learnings
- `image`'s `HdrDecoder` hard-matches first 10 bytes == `#?RADIANCE`; the rest of the Radiance format is signature-agnostic, so a line-1 rewrite is sufficient. `HdrEncoder::new(&mut Vec<u8>)` works (`&mut W: Write`) — handy for in-memory fixtures.
- **CI clippy scope ≠ local:** CI lints `-p bif_math -p bif_renderer -p bif_viewport` (not bif_core, not bif_qt). Scoping local clippy to `-p bif_core` missed a workspace break. Run the exact CI command when verifying.
- **Local rustc 1.92.0 predates the lint** → local clippy can't reproduce CI's newer-stable failures. Pinning `rust-toolchain.toml` would close this gap (deferred).
- **`gh pr checks --watch` exit code is misleading** — returned 0 while checks had *failed*. Always read the actual per-check states, not just the exit code.
- **`main` is not branch-protected** — no required checks, so the `claude-review` job (an infra flake this session: internal `tsconfig` error, `is_error:true`) is advisory and doesn't block merges.
