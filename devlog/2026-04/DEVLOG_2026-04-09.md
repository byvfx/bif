## Learnings

- `UsdShadeShader::GetInput(name)` returns a truthy `UsdShadeInput` if the attribute is *declared* on the prim, not merely if it's authored. Must pair with `IsAuthored()` or `HasConnectedSource()` checks when writing defensive extraction code.
- Embree 4 faceVarying subdivision topology: `rtcSetGeometryTopologyCount(geom, N)` enables additional topology slots, `rtcSetGeometryVertexAttributeTopology(geom, attrib_id, topology_id)` maps vertex attributes to topology slots, and the topology's index buffer is set via `RTCBufferType::Index` with the matching slot. Topology 0 inherits the default polygon index buffer automatically.
- USD DomeLight_1 is a distinct schema class, not a subclass of UsdLuxDomeLight. Requires separate `IsA` check + include.
