- Viewport edge tint: wrapping `QStackedWidget` in a `QFrame` with `contentsMargins(2,2,2,2)` + a styled background fills the margins as a "border" — cheaper than painting.

## Learnings

- **QSS stylesheet composition with dynamic colors**: `QString::fromLatin1(...).arg(...)` chains work but the `%1..%10` placeholder order matters. Got tripped once by reordering `.arg()` calls; once the `%` tokens were numbered explicitly, it stabilized.
- **`breadcrumb_set_path` + pill coexistence**: when a widget API's refresh pattern is "clear everything", adjacent permanent widgets need to live in a sibling layout, not inside the cleared container. Cheap but easy to miss.
- **Piggybacking signals**: `layer_state_revisionChanged` is a useful catch-all for "stage/layer world just shifted" — using it instead of minting separate signals for stage-path / edit-target kept the signal graph tight.
- **`is_anonymous && is_muted` isn't the real writability check** — `SdfLayer::PermissionToEdit()` is. Landing the pragmatic version now and deferring the FFI to Tier 1.5 kept momentum; the distinction won't bite until a user opens a stage where the root layer is read-only-baked (rare but real on studio published assets).
