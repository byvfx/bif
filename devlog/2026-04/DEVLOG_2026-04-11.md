## Learnings

- `Path::components()` on Windows treats `/` and `\\` as both separators, but on Linux it treats `\\` as a literal character in a filename. That's why a single shared literal wouldn't round-trip on both targets without a cfg split.
- The refactor campaign timing: Phase 1 started 2026-03-28, commit `3ab13d7` closed phases 2-5 by 2026-03-29. The tracking doc just never got updated because each session focused on shipping the code, not maintaining the plan doc. Lesson: when closing a phase, update the plan doc in the **same commit** as the code, not in a separate "docs: update status" commit that gets deferred.
- The `StatsPanelParams` borrow-splitting pattern from `render_ui.rs` turned out to be unnecessary after sub-struct decomposition. Typed containers (`GpuContext`, `SceneManager`, etc.) let callers borrow orthogonal sub-fields independently, so most new code never needs the param-struct pattern. The old one stays as a one-off.
- Pre-existing clippy errors in `ivar_state.rs` suggest clippy was upgraded between sessions and introduced a deny-by-default check that hadn't fired before. That's a separate cleanup task — not something to bundle into the refactor wrap-up.
