# BIF v0.13.0 Announcement — LinkedIn + Instagram

**Narrative constraint:** egui UI is being replaced by Qt in v0.15.0. Avoid leaning on UI chrome for hero visuals — those screenshots go stale fast. Lean on rendered output + architecture story. Explicitly telegraph the Qt migration so the audience is primed for the visual reset.

**Hero story:** v0.13.0 is the plumbing release. Persistence, architecture deepening, USD feature expansion. The boring-but-foundational work that makes v0.14.0 Layer-Aware Stage possible.

## LinkedIn post

Shipped v0.13.0 of BIF — the plumbing release.

BIF is a USD orchestration tool for VFX I'm building from scratch in Rust. Katana's layer awareness + Houdini's procedural power, on wgpu + USD + Embree. Solo side project.

This isn't a flashy release. It's the one where the pipes got laid so the real features can land next.

What shipped in 0.13.0 "Pipeline Foundation":

→ **Persistence** — .bif/.bifa project files, save/load, eval modes (Auto / Manual / OnMouseRelease), cache nodes with bypass. The thing that turns "demo" into "tool."
→ **Subdivision surfaces + CPU displacement** with faceVarying UVs and native MaterialX displacement
→ **DomeLight_1** schema support
→ **SceneQuery trait** — decoupled scene providers. Architectural runway for the layer-aware stage.
→ **FFI bridge split** — cpp_bridge.rs 4,542 → 3,651 LOC, extracted ffi_raw + ffi_convert. 44 new tests run without C++ DLLs.
→ **UsdStage Sync fix** — dropped the unsafe impl, wrapped in Arc<Mutex>. Small diff, big peace of mind.
→ **Embree feature-gated** — optional build dependency

The M29.5 egui UI overhaul also landed, but I'm not going to flex it — the entire frontend is getting replaced by Qt in v0.15.0, so this is the last release with the egui look. The architecture work underneath is what I care about, and it's UI-agnostic: SceneQuery, the FFI split, and the Sync fix all survive the Qt port unchanged.

Why this release matters: it clears the runway for v0.14.0 **Layer-Aware Stage** — where BIF starts reading USD sublayer stacks, edit targets, and opinion sources. That's the version where the Katana half of the pitch gets real.

Roadmap: v0.14 layer-aware stage → v0.15 Qt migration → v0.16 edit ops + save-to-USD.

Full changelog: https://github.com/byvfx/bif/blob/main/CHANGELOG.md

### Capture tips

- Render the hero shot offline at 2x target resolution, downsample for sharpness
- Code shots: use a consistent editor theme across all releases for visual continuity
- Record terminal at 60fps for smooth text scrolling
- For the carousel, bake a dark background gradient template so every slide looks like the same brand
- 1:1 square for IG carousel, 9:16 vertical for Reels, 16:9 for LinkedIn video
- Avoid any visible egui widgets (buttons, tabs, sliders) in shots you want to still look current in 6 months
