## Session 3 — v0.15-qt Commit 1b (mute pipeline)

### Duration
~45 min (research was most of it)

### Goals
- Ship B2: layer mute actually affects composition, not just the UI checkbox

### What I Did
- **Much simpler than planned.** Read `scene_loader.rs::load_usd_scene` expecting to have to design a "refresh scene from live stage" API. Turns out the loader already preserves mutes across reopens — lines 1496-1508 snapshot `scene.layer_state.muted` at entry and replay via `load_usd_with_stage_muted` before payloads fetch. Comment at 1492-1495 spells out the design ("implicit stage reopens — variant changes, mute toggles, etc.").
- **Fix is pure wiring.** In `bif_qt/src/main_window.rs::set_layer_muted`:
  1. Update shell mirror (existing behavior preserved).
  2. If no `current_stage_path` (demo stack), stop. No regression.
  3. Else: mutate `renderer.scene.layer_state.muted` via `with_viewport_mut` + call `renderer.load_usd_scene(&path)`. Loader picks up the muted set, reopens with `load_usd_with_stage_muted`, re-extracts, rebuilds GPU via `reload_working_scene`. Empty-scene case (muting the def-providing layer) handled inside `finalize_usd_scene`.
  4. Refresh shell mirror from freshly-composed stage; bump `layer_state_revision` + `scene_browser_revision`.
- **Skipped `reset_scene_state` on purpose** — that wipes `scene.layer_state` which would erase the mute snapshot the loader depends on. `finalize_usd_scene` overwrites USD halves of SceneManager internally. Post-Phase-F node-graph restoration may want a "reset node caches but preserve layer_state" variant.
- Workspace: cargo check, fmt, clippy `-D warnings` all clean on `bif_qt`.

### Learnings
- **Read the existing code before designing a new API.** I had a plan for `Renderer::refresh_scene_from_live_stage()` that turned out to be unnecessary — the loader was already designed to be called repeatedly on mute changes. The hint was there in the `load_usd_with_stage_muted` name and the 1492-1495 comment. Lost maybe 20 minutes building a mental model around the wrong assumption.
- `SceneLayerState::muted` is the authoritative set — `LayerInfo::is_muted` is a derived flag that `SceneLayerState::from_stage` reconstructs from the composed stage. Don't need to manually flip per-layer flags; reload does it.
- The Qt-side `scene_layer_state` is a **mirror** of `renderer.scene.layer_state`. Mutations need to flow to the renderer side *before* reload so the loader snapshots the right set, then mirror gets refreshed from renderer after.
