## Learnings
- **Pick indices align with `scene.instances.prim_paths`, not `working_scene.instances()`** — not a thing a first-principles reading would reveal without tracing `rebuild_pick_scene` → `select_at_screen`. Follow the function that's *known to work* for selection (`select_at_screen`) and copy its lookup exactly. The working_scene vs scene.instances split looked symmetric; it's not.
- When wiring a new renderer behavior, the pattern is: qprop for UI binding + invokable that updates both qprop and renderer field + menu `QAction::toggled` → invokable. Zero new renderer API if the field is already `pub` — which most `display_settings` fields are.
