## Architecture Notes

- **Blue noise default:** BlueNoise is the default sampler mode — strictly better for denoiser input
- **Pixel filter default:** Box for viewport (fast), Mitchell for batch (quality)
- **Progressive accumulation:** Non-box filters use weight_buffer for correct weighted averaging
- **Texture provenance:** Generated by `scripts/gen_blue_noise.py` (void-and-cluster, seed 42)
