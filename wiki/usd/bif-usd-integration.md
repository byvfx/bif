# BIF USD Integration

How BIF uses USD as its scene description backbone — the hybrid workflow combining procedural nodes with layer-aware editing.

## Hybrid Approach

BIF takes a hybrid approach to USD:

1. **Procedural nodes** (egui-snarl) generate and transform scene data
2. **Layer awareness** allows editing specific USD layers (edit targets)
3. **Export pipeline** writes clean USD files

This differs from pure procedural (Houdini) or pure layer-editing (usdview) approaches.

## C++ Bridge

USD has no official Rust bindings. BIF uses a C++ bridge:

- Lives in `bif_core/cpp/usd_bridge/`
- Built via CMake from `bif_core/build.rs`
- Requires Visual Studio 2022 C++ workload
- NOT thread-safe — bif_core tests must use `--test-threads=1`

The bridge exposes:

- Stage loading/saving
- Prim traversal and property access
- Schema operations (UsdGeom, UsdShade)
- Layer manipulation

## Export Pipeline

`export_scene()` in `bif_core/src/usd/export.rs`:

- Traverses the node graph evaluation result
- Creates USD prims with proper schemas
- Handles materials (OpenPBR → UsdPreviewSurface mapping)
- Writes geometry, transforms, instancing data
- Outputs clean `.usda` or `.usdc` files

## Scene Browser Integration

The `CompositeProvider` merges:

- USD stage data (loaded via C++ bridge)
- Procedural prims (generated by nodes)
- Cached via `CachedSceneGraph` for performance

## Layer-Aware Editing (v0.16, shipped)

v0.16.0 (2026-04-28) shipped C4a + C4b: open an existing USD stage, pick a working layer, edit through `EditOperation` / `EditHistory`, and save the active layer with Ctrl+S. Operations now cover Transform, Visibility, MaterialAssign, MaterialParamOverride, VariantSelect, ReplaceLayerContents (USDA Apply round-trip), and SetShaderId (shading-model swap). Writes go through `UsdEditContext(stage, working_layer)` in the C++ bridge.

The Apply-only USDA panel, Material Sheet, shading-model dropdown, and transform gizmo also landed in C4b.

_Future._ Live keystroke-level USDA preview, node-driven opinion authoring (procedural nodes still flow through `export_scene()`), cross-stack undo unification, vertex editing, animation overrides, layer diff UI, anonymous session layer, and rich payload policies are deferred. See `BIF_USD_WORKFLOW.md` for the design sketches.
